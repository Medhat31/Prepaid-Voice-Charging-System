Prepaid Voice Charging System - Project Documentation

1. Project Overview

The Prepaid Voice Charging System is a comprehensive telecommunications simulation that handles real-time voice call charging, user management, and Interactive Voice Response (IVR) services. It is divided into multiple interconnected modules, each simulating a real-world component of a telecom network.

2. System Architecture

The system is composed of four primary modules communicating with a central PostgreSQL database.

graph TD UE[User Equipment - UE] MSC[Mobile Switching Center - MSC] IVR[Interactive Voice Response - IVR] CRM[Customer Relationship Management - CRM] DB[(PostgreSQL Database)] UE <-->|UDP Audio Stream| MSC MSC <-->|JDBC| DB IVR <-->|HTTP GET /balance| CRM CRM <-->|JDBC| DB IVR <-->|FastAGI| Asterisk((Asterisk PBX))

Module Descriptions

  1. User Equipment (UE): A Java application simulating a mobile phone. It captures real audio from the system microphone using TargetDataLine and streams it over UDP to the MSC.
  2. Mobile Switching Center (MSC): The core switching and charging node. It intercepts the UDP audio stream, tracks call duration, and deducts balance from the database in real-time.
  3. Interactive Voice Response (IVR): A Java FastAGI script running on Asterisk. It provides a bilingual (Arabic/English) menu for users to check their balance.
  4. CRM & Web Frontend: A Jakarta EE REST API running on Tomcat, providing endpoints to add/delete numbers and query balances. It includes an HTML/JS frontend for administrators.

3. Real-Time Charging Flow

When a user initiates a call, the MSC processes the call setup, performs initial charging, and triggers an asynchronous background task to handle mid-call billing every 60 seconds.

4. IVR Balance Check Sequence (API Integration)

The IVR system has been decoupled from direct database access. It now securely queries the CRM via REST API to retrieve subscriber balances.

6. Recently Implemented Features

  • 🎙️ Real Audio Capture (UE Module): Implemented TargetDataLine integration to capture real-time audio directly from the user's system microphone, replacing empty dummy bytes.
  • 🌐 CRM REST API & Decoupling: Built a new GET /api/phonebook/{msisdn}/balance endpoint in the CRM. Re-architected the IVR module to fetch balances via HTTP instead of direct DB connections.
  • 🌍 Advanced Arabic Audio Processing: Implemented a custom recursive algorithm in IVR.java to isolate hundreds, tens, and units, mapping them accurately to Asterisk's internal dictionary and inserting the Arabic "and" (و) conjunction in the correct syntactic order.
  • 🚀 Tomcat WAR Deployment Stability: Replaced static file-system paths with classpath resource loading for database properties. Explicitly registered JDBC drivers and fixed CDI instantiation errors.
